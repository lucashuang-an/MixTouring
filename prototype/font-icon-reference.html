字体使用规范（符合项目约束）
字重全部 400/500：正文用 400 Regular，标题用 500 Medium，绝不用 Bold（700+），符合项目"no bold"约束。
仅加载 2 个字重：400 + 500，避免加载过多字重拖慢加载速度。Noto Sans SC 文件较大，建议用 unicode-range 或 display=swap 异步加载。
降级策略：'Inter','Noto Sans SC',-apple-system,sans-serif — Web 字体未加载时回退系统字体，不影响可用性。
字号体系建议：大标题 24px / 小标题 17px / 正文 15px / 辅助 13px / 标签 11-12px，letter-spacing 0.01em。

四、MixTouring 专项推荐方案
结合项目约束（墨蓝远行配色 / Apple 风格 / no bold / 轻量组件 / 0.5px hairline）
推荐组合方案
字体：Inter (400/500) + Noto Sans SC (400/500)，通过 Google Fonts CDN 引入。正文 400、标题 500，符合 no-bold 约束。降级到系统字体栈保证可用性。
图标（已选定）：Heroicons，纯 SVG 无框架依赖，线性 1.5px 描边贴合全站 0.5px 发丝线风格。可直接引入 CDN 的 SVG，或用 <svg><use href="#…"></svg> 本地 sprite 引用，选中态以 currentColor 切换 var(--accent)。[$TRAE_REF](https://allsvgicons.com/blog/best-free-svg-icon-libraries-2026/)
图标补充：Heroicons 共 292 枚（线性+实心），本产品功能面（搜索/定位/交换/日期/交通/预算/AI/收藏等）已覆盖；若个别旅游类图标缺失，可从 Lucide（1,500+）单独补充单枚，避免引入第二套完整库产生风格冲突。
图标尺寸：导航/标签栏 22-24px，行内图标 16-18px，按钮内图标 18-20px。颜色用 currentColor 继承文本色，选中态切 var(--accent)。
需替换的当前手写 SVG：搜索图标 → search，地图标记 → map-pin，用户 → user，交换 → arrow-left-right，AI 闪光 → sparkles，品牌 Logo 保留手写 SVG。
